# 📰 MediaPost - Content Sharing Platform

MediaPost is a web-based platform where users can create, share, and explore posts.  
It is designed to provide a simple and clean interface for publishing content and interacting with posts.

---

## 🚀 Features

- ✍️ Create and publish posts  
- 📖 View and explore posts  
- 👤 User authentication (login/signup)  
- 🖼️ Media/image support  
- 📊 Organized content display  

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite (Development)
- Deployment: AlwaysData
