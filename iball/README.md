# 🎓 iBall E-Commerce Frontend Website (Educational Project)

This is a fully designed frontend website called **iBall**, created using HTML, CSS, and JavaScript for learning and practice purposes.

It simulates a real e-commerce platform with product listings, cart system, chatbot, OTP login simulation, animations, and UI effects.

---

## 🚀 Project Purpose

This project is created for:
- 📚 Learning frontend web development
- 🎨 Practicing modern UI/UX design
- 💻 Understanding JavaScript DOM manipulation
- 🛒 Simulating an e-commerce system

---

## ⚠️ Disclaimer

This project is **not an official or real commercial website**.  
It is created only for **educational purposes and skill development**.

---

## 📌 Features

### 🖥️ UI & Design
- Modern responsive layout
- Hero section with animation
- Product cards with hover effects
- Category section & promotional banners
- Dark mode support

### 🛒 E-Commerce Features
- Product listing system (JavaScript dynamic rendering)
- Add to cart functionality (localStorage)
- Favorite/wishlist system
- Cart counter tracking

### 🤖 Interactive Features
- Chatbot with simple AI responses
- OTP generation (demo system)
- Search bar toggle animation
- Intro loading animation

### 🎞️ Animations
- Flipbook product image animation
- Logo intro animation
- Hover effects and transitions

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox + Grid + Animations)
- JavaScript (DOM + Events + LocalStorage)
