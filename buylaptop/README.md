# 💻 BuyLaptop - Smart Laptop Recommendation Website

A Django-based web application that helps users explore and compare laptops based on categories, brands, and specifications.

---

## 🚀 Features

- 🏷️ Brand & Category Filtering
- 🔍 Laptop Comparison
- ⭐ Ratings & Pricing
- 🛒 Amazon & Flipkart Links
- 📊 Smart Data Handling with Django

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite (Dev)
- Deployment: PythonAnywhere
